# pdf-editor
inorder to load up the website you have to do these things

1st: go to main.java

2nd: make sure to press run at the top of the screen and press "start debugging" or press f5 while you are in the java file

3rd: go to you favorite browser and put, http://localhost:8000/ into the search bar 

4th: enjoy our PDF editor

note: this should run on both windows and mac, please let us know if there are any issues
